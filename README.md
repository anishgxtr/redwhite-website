# REDWHITE. Motion Website

Self-contained HTML/CSS/JavaScript motion website.

## Files
- index.html — master page
- styles.css — visual system and animations
- script.js — interactions and motion
- assets/REDWHITE.-3.png — supplied logo
- assets/first.mp4 — local video used by the showreel
- assets/icons/*.svg — local camera/lens/film elements

## Run
Open `index.html`, or serve the folder:
`python3 -m http.server 8080`

## Video
The exact R2 `first.mp4` referenced in the earlier conversation was not available as a downloadable conversation asset in this environment. Therefore `assets/first.mp4` is a small local fallback clip so the website is immediately runnable. Replace that file with your actual `first.mp4`; no code changes are needed.

## Palette
Wine `#800000`
Cream `#FFFDD0`
Black `#000000`

No external image/icon libraries are used. Google Fonts are the only remote CSS dependency.
